A MEF 3 segment directory is now listed once per lookup instead of once per file kind, and `MEF3RecordingInterface.get_channel_survey` gives the empty channels, the unreadable channels and the incomplete segments of a session in one pass. A segment directory with two or more files of one kind is refused again even when it also lacks a file, a segment whose data file holds only its header and whose index lists no block is empty rather than incomplete, `get_available_channel_ids` lists a channel with no metadata file, and `get_channel_sampling_frequencies` refuses a `channels_to_skip` name that is not in the session.
