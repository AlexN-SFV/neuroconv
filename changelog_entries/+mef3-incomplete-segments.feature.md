A MEF 3 segment directory that holds data but is missing its metadata, index or data file is now left out with a warning, keeping the rest of its channel, instead of failing the session. `MEF3RecordingInterface.get_incomplete_segments` lists such segments and the files they lack, and `MEF3RecordingInterface.get_unreadable_channel_ids` lists the channels left with no readable samples, which the interface refuses unless they are in `channels_to_skip`, as it does empty channels. `get_channel_sampling_frequencies` takes `channels_to_skip`, so a channel with no metadata file can be left out of it.
