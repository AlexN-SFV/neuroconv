Added `MEF2RecordingInterface` for MEF 2.0 and 2.1 (Multiscale Electrophysiology Format) recordings, directories of `.mef` files as published by IEEG.org and Pennsieve Discover. It reads them with neuroconv's own reader and the RED decoder of the MEF 3 interface, checked block by block against the maximum, minimum and CRC every MEF 2 block stores, since no Python MEF 2 reader exists. Samples are stored as int32 counts with each channel's voltage conversion factor, sign included, as the gain. A recording with gaps is written as one `ElectricalSeries` per uninterrupted run at the nominal sampling rate, runs breaking on the files' discontinuity flags, with the runs in a `runs` `TimeIntervals` table; IEEG.org `annotations.xml` files go to an `annotations` table. Channels at different rates are read one `stream_name` at a time; block CRCs can be checked with `validate_crc=True`; encrypted files are refused, and the header's subject fields are never read. Install via `pip install "neuroconv[mef]"`.
