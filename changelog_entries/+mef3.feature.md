Added `MEF3RecordingInterface` for MEF 3.0 (Multiscale Electrophysiology Format) sessions (`.mefd` directories). It reads them with neuroconv's own reader and a RED decoder that matches meflib, the reference implementation, bit for bit, so neither pymef (whose wheels are x86_64-only) nor MNE is needed; numba compiles the decoder, with a pure-NumPy fallback where numba is unavailable. Samples are stored as int32 counts with each channel's units conversion factor as the gain. A session with gaps is written as one `ElectricalSeries` per uninterrupted run, at the nominal sampling rate, with the runs in a `runs` `TimeIntervals` table; MEF records go to a `records` table. Lossily stored (scaled or detrended) blocks are decoded as meflib decodes them, with a warning; encrypted sessions are refused. Install via `pip install "neuroconv[mef]"`.
