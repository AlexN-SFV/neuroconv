Fixed `EDFRecordingInterface` keeping only the first file's `annotations` and `runs` tables when several discontinuous EDF+ (`EDF+D`) files are written into one NWB file through a `ConverterPipe`; every later file's rows were dropped without a warning. The tables are now shared, with a `source_file` column naming the file each row came from. The sub-interfaces from `split_by_offset`, which all come from one file, still write that file's rows only once. A same-named table with other columns, which this interface did not write, is left alone with a warning.
