Fixed `EDFRecordingInterface` keeping only the first file's `annotations` and `runs` tables when several discontinuous EDF+ (`EDF+D`) files are written into one NWB file through a `ConverterPipe`; every later file's rows were dropped without a warning. The tables are now shared, with a `source_file` column naming the file each row came from. Interfaces over the same EDF file, whether `split_by_offset` partitions or interfaces built separately with different `channels_to_skip`, still write that file's rows only once per NWB file. A same-named table with other columns, which this interface did not write, is left alone with a warning.
