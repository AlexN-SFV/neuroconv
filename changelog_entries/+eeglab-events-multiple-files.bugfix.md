Fixed `EEGLABRecordingInterface` raising on a duplicate `events` table when a second EEGLAB dataset is written into the same NWB file through a `ConverterPipe`, and raising from `add_epoch_column` when the NWB file already had an `epochs` table with rows. The `events` and `epochs` tables are now shared, with a `source_file` column naming the `.set` file each row came from. An `epochs` or `events` table with other columns, which the interface did not write, is left alone with a warning. `BrainVisionRecordingInterface` no longer writes a recording's `markers` and `segments` twice when two interfaces over the same `.vhdr` (such as one with the complementary `channels_to_skip`) go into one NWB file. Both now share one helper with `EDFRecordingInterface`, which writes each source file's rows once per NWB file.
