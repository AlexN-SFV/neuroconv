Documented how channel metadata from an external source — a BIDS `channels.tsv`, a lab spreadsheet — reaches the NWB electrodes table, in a new user guide page. Any property set on the recording extractor becomes a column, which was previously discoverable only from the `add_electrodes_to_nwbfile` docstring; the page also covers the property names NeuroConv maps onto the NWB standard (`brain_area` becomes `location`, and so on), that `metadata['Ecephys']['Electrodes']` supplies column descriptions rather than values, and why a unit disagreement has to be corrected through the channel gains instead.
