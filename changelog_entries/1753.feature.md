Added `EEGLABRecordingInterface` for converting EEGLAB (`.set` / `.fdt`) data to NWB. The reader is dependency-light (`pymatreader` for the `.set` struct and NumPy for the `.fdt` binary; no MNE) and supports both EEGLAB layouts from the `.set` path: a self-contained `.set` with inline data, and a `.set` paired with an external `.fdt`. The continuous signal is written as an `ElectricalSeries` with channel names and locations, and `EEG.event` markers are written to a `TimeIntervals` table (disable with `write_events=False`). Epoched datasets (`EEG.trials > 1`) are written as one `ElectricalSeries` per epoch (named `ElectricalSeriesEpoch{index}`) into a single NWB file sharing one electrodes table, each placed at the epoch's real time in the source recording (recovered from `EEG.urevent`) so they share one session timeline; the per-epoch boundaries and time-locking event types are written to the NWB `epochs` table (disable with `write_epochs=False`). `subject_id` is taken from `EEG.subject`; subject demographics from the in-struct `EEG.BIDS.pInfo` (a copy of `participants.tsv`) are imported only when `import_bids_subject_metadata=True`.
