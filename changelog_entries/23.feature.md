`MEF2RecordingInterface` can write some of a recording's runs, to split a long recording over several NWB files: `run_indices`, or `select_runs` on an interface over the whole recording, selects the runs, and `get_runs` / `describe_runs` list them with their start, samples and size from the headers alone. A selected run keeps the series name, starting time and samples it has in a file of the whole recording, the `runs` table gives each run's index in the whole recording, and only the annotations that overlap the selection are written, with a `spans_parts` column.
