Added `BrainVisionRecordingInterface` for BrainVision Core Data Format recordings (`.vhdr` / `.vmrk` / `.eeg`). It reads the files with neuroconv's own NumPy reader rather than neo's, which ignores the channel resolution of floating-point data, cannot decode headers written in Latin-1 or Windows-1252, and places every marker one sample late. Each channel's resolution and unit (`V`, `mV`, `µV`, `nV`) become its gain for `INT_16`, `INT_32` and `IEEE_FLOAT_32` data in either orientation, and samples are read lazily from the memory-mapped `.eeg`. Markers are written to a `markers` `TimeIntervals` table; a recording paused and resumed is written as one `ElectricalSeries` per `New Segment`, placed at the time the marker states, with the date of the `New Segment` at the first sample as `session_start_time`. Several recordings written into one file share the `markers` table, with a `source_file` column. Install via `pip install "neuroconv[brainvision]"`.
