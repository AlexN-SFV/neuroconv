Fixed `EDFRecordingInterface` dropping the annotations of continuous EDF+ (`EDF+C`) files. Only discontinuous (`EDF+D`) files had an `annotations` table, because SpikeInterface's reader, which reads `EDF+C`, does not expose the `EDF Annotations` signals. They are now read with the parser the `EDF+D` path uses and written to the same `annotations` table, timed from the recording's first sample and moved with it by `set_aligned_starting_time`. The table's rows are sorted by start time on both paths, since writers do not store their annotations in time order. A file whose annotations cannot be parsed still converts, without them and with a warning.
