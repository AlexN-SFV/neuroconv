# MEF 2 test fixtures

Excerpts of public MEF 2 recordings, cut by `build_mef2_fixtures.py`, which says how to download the sources
and rebuild them. Each `.mef` file keeps its source's blocks byte for byte; only its header and block index
are rewritten for the shorter file.

- `Discover13_AD3_excerpt/`, `Discover13_AD3_clock_step/` and `Discover13_annotations_excerpt.xml`: from
  "Intracranial EEG Epilepsy - Study 5", Mayo Clinic, Pennsieve Discover dataset 13, version 1, released under
  CC0 1.0. MEF 2.0.
- `PennEPI00082_LI07_excerpt/`: from "PennEPI00082", Penn Center for Neuroengineering and Therapeutics,
  Pennsieve Discover dataset 549, version 1 (https://discover.pennsieve.io/datasets/549), released under the
  Creative Commons Attribution license. MEF 2.1.
